
# 🕵️‍♂️ Dev Detective

**Dev Detective** is a simple and intuitive web application that allows users to search for GitHub accounts by username and displays detailed profile information.

---

## 🔍 Features

- 🔎 Search GitHub users by username
- 📄 View public profile information:
  - Avatar
  - Name
  - Bio
  - Location
  - Number of Public Repos
  - Followers / Following
  - GitHub Profile Link
- ❌ Handles invalid usernames or missing data gracefully
